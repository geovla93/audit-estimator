The bootstrap and Slang versions were checked against npm registry package metadata on 2026-10-14; Commander 15.0.0 was checked against its upstream package manifest on 2026-10-15. Zod 4.4.3's installed package manifest confirms its MIT license and no install-time lifecycle hooks (`preinstall`, `install`, `postinstall`, `prepare`). Slang 1.3.9 ships ESM entry points and bundled WebAssembly assets; its package manifest declares no lifecycle scripts. Commander is imported only by the local CLI shim, is not bundled into the library entry, and has no install-time lifecycle hooks in its upstream package manifest. Picomatch 4.0.7's documented literal matching options and the smol-toml parser's unsafe-key rejection option are used behind bounded analyzer-owned adapters; neither package nor `@types/picomatch` declares install-time lifecycle hooks. `smol-toml` 1.9.0 is newer than the 1.7.1 fix for [CVE-2026-85730](https://github.com/advisories/GHSA-7w5x-hrqm-74c2), which affects versions through 1.7.0; metadata parsing uses the 1.9.0 `unsafeKeyBehaviour: 'throw'` option. No dependency lifecycle script has been allowlisted; pnpm 11 uses `allowBuilds` in the repository-root `pnpm-workspace.yaml` if installation proves a specific dependency script is required. Add only a reviewed required package there.
