# Verification ledger

This ledger maps safety, measurement and stability claims to executed tests. The
current-platform entries are updated after the corresponding local command has
run. Integration and E2E entries run from a fresh build; unit and coverage
commands import source and do not build. Fixtures are read as data and their
own scripts are never run.

11.28.4. The local result is not evidence for Linux or Windows behavior. The
future matrix is maintained Node 24.11+ on Ubuntu, macOS and Windows; Plan 015
owns running that matrix and packed-artifact smoke tests.

Boundary scanner: `scripts/check-boundaries.mjs` uses the TypeScript 7 native API
(`typescript/unstable/sync`, `typescript/unstable/ast`, `typescript/unstable/ast/is`),
pinned by `API_VERSION = '7.0.2'` to the exact `typescript` devDependency. It scans
trusted `src/**/*.ts` through the repository tsconfig and is covered by 31 virtual
source-graph self-tests. The reviewed worker spawn path is pinned by SHA-256
fingerprints of the AST shape (node kinds, with leaf text) of `packageWorkerPaths`,
`trustedEnvironment` and `spawnWorker`. Maintenance contract: a TypeScript upgrade must
update `API_VERSION` and re-run the self-test and scan; any intentional edit to those
